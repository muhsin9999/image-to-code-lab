# Next improvements

The toolkit is a visual reconstruction baseline. Work that should follow:

1. **Generate UI graphics as code.** Charts, tables, progress indicators and other interactive graphics should be React/SVG/CSS components. Crop only a complete independent illustration or photograph when its original file is unavailable. The Fieldwork bar chart already follows this rule; its district map is a crop.
2. **Implement real interaction contracts.** Test each visible control's intended result. The current automatic checker covers declared actions and accessible open/close disclosures, but a search field, pagination or project button can still be inert. Distinguish local prototype state from backend delivery.
3. **Improve mobile feedback.** The checker currently reports desktop sidebar text as hidden while a working mobile drawer is closed. Verify alternate content after opening the drawer, and avoid counting expected responsive substitutions as errors.
4. **Reduce agent time.** Add reusable palette, chart and component probes to the initial evidence or a small batch tool. Record external commands consistently. Stop repair rounds when measured gains plateau unless a real content or behavior defect remains.
5. **Measure transfer.** Test unseen commerce, editorial, documentation, form, dashboard and right-to-left pages. Keep screenshots, assets, model/settings and evaluation rules fixed within each comparison.
